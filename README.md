# AppleSkin for Horizon

A native mixin mod (`.hnmod`) for [Horizon](https://github.com/horizon-rust/horizon) (Minecraft: Java Edition 26.3 rewrite in Rust).

Adds food and saturation HUD indicators with 1:1 Minecraft Java parity:
- **Saturation Overlay:** Golden border and glow around active saturation drumsticks matching original `icons.png` pixel art.
- **Food Value Preview:** Pulsing preview drumsticks and preview saturation border when holding edible food items.
- **Configurable:** Enable or disable overlays anytime via `Options > Mods > AppleSkin`.

## Author
Developed by **CayMac**.

## Installation
Place `appleskin_horizon-1.0.0.hnmod` into your Horizon `mods` folder, or build it into your native client instance via the Horizon Launcher.
